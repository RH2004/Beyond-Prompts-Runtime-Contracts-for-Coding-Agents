## 1. The task the agent was given

Add a request handler `handle_data_manifest(params)` in `app/api/handlers.py`.
`params["dir"]` (default `""`, the `data/` directory itself) is a directory path relative to the project's `data/` directory, made of segments separated by `/`; it is invalid (`(400, {"error": "invalid path"})`) when it is not a string or has an empty, `.` or `..` segment (the default `""` is allowed) and not found (`(404, {"error": "not found"})`) when no such directory exists.
The handler returns `(200, {"entries": [{"path": p, "bytes": n}, ...]})` with one entry for every regular file in that directory and
in all its sub-directories: `p` is the path relative to that directory written with `/`, `n` the size in bytes; entries are
sorted by `p` as a string.

+def handle_data_manifest(params: dict) -> tuple[int, dict]:
+    raw = params.get("dir", "")
+    if not isinstance(raw, str):
+        return 400, {"error": "invalid path"}
+    if raw == "":
+        segments: list[str] = []
+    else:
+        segments = raw.split("/")
+        if any(seg in ("", ".", "..") for seg in segments):
+            return 400, {"error": "invalid path"}
+
+    target = _DATA_DIR.joinpath(*segments)
+    if not target.is_dir():
+        return 404, {"error": "not found"}
+
+    entries = [
+        {"path": path.relative_to(target).as_posix(), "bytes": path.stat().st_size}
+        for path in target.rglob("*")
+        if path.is_file()
+    ]
+    entries.sort(key=lambda entry: entry["path"])
+    return 200, {"entries": entries}
