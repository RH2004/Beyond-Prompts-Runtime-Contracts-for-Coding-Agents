## 1. The task the agent was given

Add a request handler `handle_find_by_extension(params)` in `app/api/handlers.py`.
`params["ext"]` is a file extension of 1 to 8 letters or digits, without the dot; any other value, or a missing one, gives
`(400, {"error": "invalid extension"})` (checked first). `params["dir"]` (default `""`, the `data/` directory itself) is a directory path relative to the project's `data/` directory, made of segments separated by `/`; it is invalid (`(400, {"error": "invalid path"})`) when it is not a string or has an empty, `.` or `..` segment (the default `""` is allowed) and not found (`(404, {"error": "not found"})`) when no such directory exists.
The handler returns `(200, {"files": [...]})` with the paths, relative to that directory and written with `/`, of all files in it and in
its sub-directories whose name ends with `.` plus the extension (case-insensitive), sorted as strings.

+def handle_find_by_extension(params: dict) -> tuple[int, dict]:
+    ext = params.get("ext")
+    if not isinstance(ext, str) or _EXT_RE.fullmatch(ext) is None:
+        return 400, {"error": "invalid extension"}
+
+    rel_dir = params.get("dir", "")
+    if not isinstance(rel_dir, str):
+        return 400, {"error": "invalid path"}
+    if rel_dir != "":
+        segments = rel_dir.split("/")
+        if any(segment in ("", ".", "..") for segment in segments):
+            return 400, {"error": "invalid path"}
+
+    base = Path(_DATA_DIR)
+    target = base / rel_dir if rel_dir else base
+    if not target.is_dir():
+        return 404, {"error": "not found"}
+
+    suffix = "." + ext.lower()
+    files = []
+    for root, _dirs, names in os.walk(target):
+        for name in names:
+            if name.lower().endswith(suffix):
+                relative = (Path(root) / name).relative_to(target)
+                files.append(relative.as_posix())
+    return 200, {"files": sorted(files)}
